# YSM 外观附属 1.0.0-beta.1 — Forge 1.20.1

本次提供 Minecraft 1.20.1 Forge 专用安装包，包含 10 套心智娘服装与九种灾厄及其状态变体，共 67 个模型目录。模型、署名和许可保留；不包含 Spore AI 主模组或程序源码。

## 安装

- Minecraft 1.20.1、Forge 47.4.10、Java 17。
- Spore AI **2.8.0-beta.2 Forge 1.20.1**，以及主模组所需的 Spore 2.2.0j Forge 依赖。
- Yes Steve Model **2.6.5-forge+mc1.20.1**：[下载 YSM](https://modrinth.com/mod/yes-steve-model/version/2.6.5-forge%2Bmc1.20.1)。
- 将 `spore_ai_ysm-1.0.0-beta.1+mc1.20.1-forge.jar` 放入客户端 `mods`。多人游戏遵循 YSM 本身的服务端安装要求。
- 首次进入世界等待模型编译、同步后按 F8 选择心智娘外观。不要安装 NeoForge 1.21.1 的同名附属。
- 安装器会保留玩家修改过的同名模型；需要更新这些模型时，请先移出对应目录备份。卸载附属不会自动删除已导出的模型。

## 验证与限制

已在隔离的 Forge 1.20.1 发布环境安装模型，并完成心智娘及九种灾厄的原生 YSM 渲染调用；资源包描述缺失导致的加载警告已修复。完整战斗动画、全部断肢变体、多人同步和骑乘操控仍需实机验收。

模型采用 CC BY-NC-SA 4.0，安装器采用 MIT；完整署名及贡献记录见包内各模型的许可和归属文件。

# YSM Appearance Addon 1.0.0-beta.1 — Forge 1.20.1

This download targets Minecraft 1.20.1 Forge. It includes 10 Mind Girl outfits and nine Calamities with state variants, totaling 67 model directories. Model assets, attribution, and licenses are preserved. The Spore AI main mod and program sources are not included.

## Installation

- Minecraft 1.20.1, Forge 47.4.10, Java 17.
- Spore AI **2.8.0-beta.2 for Forge 1.20.1**, with its required Spore 2.2.0j Forge dependency.
- Yes Steve Model **2.6.5-forge+mc1.20.1**: [Download YSM](https://modrinth.com/mod/yes-steve-model/version/2.6.5-forge%2Bmc1.20.1).
- Place `spore_ai_ysm-1.0.0-beta.1+mc1.20.1-forge.jar` in the client's `mods` directory. Follow YSM's own server installation requirements for multiplayer.
- Wait for model compilation and synchronization after joining a world, then use F8 to choose Mind Girl appearances. Use the Forge build of the addon.
- Player-edited model folders are preserved. Back up and move those folders before intentionally replacing them. Removing the addon does not remove exported models.

## Validation and limitations

An isolated Forge release client installed the models and successfully invoked native YSM rendering for the Mind Girl and all nine Calamities. The missing resource-pack metadata warning has been fixed. Full combat animations, every damaged-body variant, multiplayer synchronization, and riding controls still need gameplay testing.
