# 非 YSM 模型投稿

[返回首页](../README.md) · [统一投稿协议与内容规范](../CONTRIBUTING.md)

**[点击这里提交非 YSM 模型](https://github.com/sx050907-png/Spore-AI-Model-Community/issues/new?template=non-ysm-model.yml)**

## 可以投稿什么

欢迎心智娘、九大灾厄及相关服装、配饰、孢子主题的模型。可提交 .bbmodel、.blend、.gltf/.glb、.fbx、.obj/.mtl、.pmx 等格式；其他格式请在表单中说明。

这些资源可以作为展示或后续适配素材。投稿、收录、转换和游戏接入是不同阶段，不保证能够转换为 YSM，不保证被纳入附属，也不表示当前 F8 能直接加载这些格式。

## 如何上传

1. 使用自己的 GitHub 账号登录并打开上方入口。
2. 填写模型名称、目标角色、文件格式、制作软件版本、作者与素材来源、许可和修改说明。
3. 将模型、必要贴图、授权记录和说明整理成 ZIP。可在表单正文中拖入 GitHub 支持的附件，或填写可直接访问的下载链接；不要上传程序安装包。平台大小或类型限制导致上传失败时，提供文件分享链接即可。
4. 附正面、侧面、背面预览；有骨骼和动画时说明骨骼结构及动画清单。尚未实机测试请如实注明。
5. 阅读投稿协议，完成必选确认后提交，等待维护者审核。Issue 公开可见，不要上传私人资料或违规内容。

本社区沿用 CC BY-NC-SA 4.0 投稿要求，作者保留著作权。改作须同时满足上游授权，保留完整署名、来源及修改说明；只有署名而没有授权不能收录。素材许可不清楚时先提供来源说明，不要先上传争议文件。

## 收录后的存放与状态

经审核收录的非 YSM 资源使用 `models/community-non-ysm/<作者ID>/<模型ID>/`，保留模型、必要贴图、预览和 ATTRIBUTION.json，不与可直接使用的 YSM 模型混放。

每个模型附说明，标注“仅展示”“待适配”或“已适配（注明适配版本和下载位置）”。原格式文件不会被自动打包进 YSM 附属。

禁止违规、侵权、色情、仇恨骚扰、隐私泄露、恶意程序等内容，完整要求见统一投稿协议。审核人员不执行模型内嵌脚本。
